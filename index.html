Privacy Policy

DATA PROCESSING & RETENTION

1. Information Stored

SparxieBookie stores only operational data necessary for core gameplay synchronization:

  • Discord User ID & Username: Linked to your profile balance, experience level, login streaks, and bank account.
  • Gameplay & Bank State: Liquid balance, vault balance, salted cryptographic PIN hashes, and loan metrics.
  • System Logs: Command names, timestamps, and execution success flags for diagnostic and health monitoring.

We do not collect, read, or store private Discord messages or voice activity.

2. Infrastructure & Data Security

All records are stored on managed cloud infrastructure utilizing Supabase (PostgreSQL). Data is protected by Row Level Security (RLS) policies. Sensitive values such as bank account PINs are hashed using salted scrypt algorithms before persistence.

3. Third-Party Sharing

User data is never sold, leased, traded, or shared with third-party advertising brokers or commercial analytics platforms. Data is utilized strictly within the scope of SparxieBookie operations.
